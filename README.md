## 🚀 Projetos em destaque

### ☁️ [SecureCorp AWS — Secure Cloud Infrastructure & DevSecOps](https://github.com/Gabriel-F4l/SecureCorp-AWS.)

**Projeto autoral de arquitetura AWS e Infrastructure as Code — versão 1.0 concluída.**

Desenvolvi um laboratório para modelar uma infraestrutura AWS segura e validar suas configurações antes de qualquer implantação.

| Pilar | O que foi desenvolvido |
|---|---|
| **Arquitetura** | Amazon VPC Multi-AZ, sub-redes públicas e privadas isoladas e S3 Gateway Endpoint |
| **IaC** | **Terraform** e **AWS CDK com Python** |
| **Segurança** | IAM, Security Groups restritivos, S3 privado e políticas de acesso |
| **Observabilidade** | VPC Flow Logs, CloudWatch Logs e AWS KMS definidos em Terraform |
| **Automação** | GitHub Actions, Pytest e Checkov |

**Evidências da validação local:** `13 testes Pytest aprovados` · `Terraform validate: sucesso` · `Checkov: 40 aprovados, 0 falhas, 1 exceção documentada`.

> **Escopo transparente:** laboratório de Infrastructure as Code, **não implantado em uma conta AWS**. As configurações CDK e Terraform são implementações separadas.
