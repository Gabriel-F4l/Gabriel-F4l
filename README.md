## ☁️ Projeto em destaque

### [SecureCorp AWS — Cloud Infrastructure & DevSecOps](https://github.com/Gabriel-F4l/SecureCorp-AWS.)

Projeto de portfólio desenvolvido por mim, com foco em **arquitetura AWS segura e validação automatizada de Infrastructure as Code**.

- **Arquitetura:** VPC Multi-AZ, sub-redes públicas e privadas isoladas, S3 Gateway Endpoint.
- **Infraestrutura como código:** AWS CDK com Python e Terraform.
- **Segurança e observabilidade:** IAM, Security Groups, controles de S3, VPC Flow Logs, CloudWatch Logs e AWS KMS.
- **Qualidade:** Pytest, Checkov e GitHub Actions.
- **Validação reportada:** 13 testes Python aprovados; Checkov com 40 aprovações, nenhuma falha e uma exceção documentada.

> **Status:** v1.0 concluída como laboratório IaC. Infraestrutura definida e validada em código, **sem implantação em uma conta AWS**.
